# OTY2-RSA0 全局路线重置与研究契约

日期：`2026-07-17`

中文名称：`OTY2-RSA0 SAR 可见响应图谱与表示诊断基础`

英文名称：`OTY2-RSA0 SAR Visible Response Atlas and Representation Diagnosis Foundation`

RSA：`Response Support Atlas`

语义冻结起点：本文件、`OTY2_RSA0_FAILURE_LESSONS_AND_NON_NEGOTIABLES.md` 与 `OTY2_RSA0_VISIBLE_RESPONSE_OBJECT_SEMANTICS.md` 完成 docs-only 提交并推送后的提交 SHA。后续实验不得为了迎合结果静默改写这三份契约；新事实只能进入独立、版本化的 addendum。

## 1. 路线重置结论

项目最终目标仍是：利用完整光学时间流提供物理车辆身份、时间关系和宽空间先验，由 SAR 在该先验内确定车辆在 SAR 中实际可见的响应位置与组织，最终支撑可审计的自动或半自动标注。当前 RSA0 不执行最终标注，也不恢复完整车辆框；它先关闭一个更基础的问题：

> 在人眼、光学身份和 SAR GT 能共同确认车辆邻域的少量清晰短序列中，哪些显示、结构和时序表示真正承载了“这是该车辆可见响应”的判断？

研究单位从“单帧候选框”“整车 GT 矩形”或“整条生命周期事件图”改为：

> 一个清晰短时序中的车辆可见响应对象。

该对象由主响应骨架、局部确定响应、间歇或可能响应、背景反事实和不可判定区域共同定义。它不是完整车体，也不是一个必须密实连通的 Mask。

## 2. 人眼在连续 SAR 中实际识别什么

在 `GM_RM017:PV002 / SAR 330–350` 的既有直接审阅中，人眼没有依靠一个恒定最亮点或完整矩形判断车辆。可重复使用的判断来自关系组合：

- 中下部近水平主响应在连续帧中可追踪；
- 主响应由连续带、断续亮段和局部热点组成，最亮局部会变化；
- 上侧短段与主带保持有限但非绝对稳定的相对关系；
- 同一序列中存在弱、中、强状态，响应宽度、连续性和局部部件会变化；
- 扇形弧、竖直强线、固定热点等背景也会持续或增强，必须通过同帧背景控制、世界稳定化和局部关系进行反事实排除；
- 与背景混合的区域需要保留为 unresolved，而不是强制正负。

因此人眼识别的是一个跨帧、关系化、部分可见的响应对象，而不是亮度中心、GT 中心、整车轮廓或单项持久像素。

## 3. 当前 8-bit SAR 灰度的能力边界

### 3.1 可以支持

- 直接显示像素坐标中的局部亮暗、方向、长度、宽度、曲率和连通关系；
- 同一显示链下的局部对比、局部中位数/MAD、高通、分位数和梯度等表示比较；
- 世界稳定坐标、研究期 GT 条件坐标和 optical proxy 条件坐标中的短时序对照；
- 主响应骨架、间歇部件、背景弧线、竖线、热点和混合区的人工审阅；
- 当前显示产品内部的跨帧出现、消失、增强、减弱和关系持续性描述；
- 以保守 scribble、polyline 和 polygon 建立显示域响应图谱。

### 3.2 不能支持

- 原始相位、绝对 RCS、复数散射中心或成像前幅度的恢复；
- 把历史 `0.03 m/pixel` 当作全图统一米制比例、真实分辨率或 PSF；
- 从灰度显示直接推断唯一物理散射机理、车辆完整不可见部位或密实车体轮廓；
- 把最亮点、灰度质心或某个固定响应带解释为车辆物理中心；
- 在跨场景映射和灰度 lineage 未解决时宣称部署级通用性；
- 用显示域事件名称证明真实 birth、split、merge、migration 或动力学机制。

若清晰 canonical 窗口在光学、SAR GT 和连续 SAR 共同审阅后仍无法形成内部一致的响应图谱，应优先判断显示域信息不足，并回查成像前幅度、复数数据、灰度映射和成像链，而不是继续增加阈值。

## 4. S1X 为什么曾经看起来成功

S1X 的正向结果是真实但范围很窄：

- 光学 annular-sector shell 在 PV002 与 PV003 中提供了宽搜索先验；
- SAR robust-z 与时序频率把宽壳层收缩为较小响应子集；
- 无目标参考盲审确实看到连续近水平响应；
- 冻结规则在同场景另一车辆上部分复现；
- 相对完整 GT 框的 precision 和 shell contraction 很高，且未接入其他车辆 GT 区域。

这些事实说明 S1X 能在宽光学壳层内提取少量保守亮响应，不能说明它已经恢复了人眼所见的主要车辆响应对象。S1X 评价使用完整 GT 框作上下文覆盖，target coverage 约为 `0.11–0.12`；当 S1D0 后续建立小规模直接可见响应参考后，因果路径的可见响应 recall 仅 `0.0265`。因此“看起来成功”的主要来源是壳层收缩、高 precision、连续亮带的视觉存在和过宽分母下的保守命中，而不是完整响应语义已经关闭。

## 5. S1D0 为什么失败

S1D0 的失败不是生命周期状态机没有运行，而是响应恢复入口没有通过：

1. discovery 因果 joint F1 为 `0.0515`，未同时超过等面积 axis-strip 与 center-region 两个光学基线；
2. 主响应 recall `0.0318`、间歇响应 recall `0.0201`，高 precision 伴随极低召回；
3. GM_RM019 正响应参考不足，不能区分映射失败与恢复失败；
4. GM_RM011 壳内包含大面积背景、混合结构和身份重叠；
5. 因果与双向路径都只带来很小的平滑增量，没有解决主要语义缺口。

实现上，失败与以下假设直接相关：

- 单帧 `robust-z` 阈值把响应对象缩成少量亮组件；
- S1X 用整窗 positive frequency 建立固定 persistent core，不能表达形态明显变化的对象；
- S1D0 又用 `ABSENT/CLOSED` 时段壳内 positive frequency 构造 inside-shell background；对当前大量静止车辆，这会把光学进入前或退出后的真实车辆响应误当背景；
- component acceptance 仍围绕壳层相交、连通片、方向和尺度兼容展开，缺少人工确认的骨架、部件关系和 unresolved 语义；
- 旧 visible-response reference 以轴对齐矩形区域存储，矩形内部仍被整体作为同类评价区域，不能精确表示细骨架和混合边界；
- 恢复入口未通过时继续生成图事件，事件名称容易超出证据能力。

## 6. 低召回证明了什么、没有证明什么

低召回证明：

- 当前 robust-z、连通片和固定持久频率组合没有覆盖人眼可见的主要响应及间歇部件；
- 当前参考和算法的对象语义不匹配；
- 在已有表示与背景排除下，高 precision 的少量亮点不能代表响应对象已恢复；
- 下一步应先改进参考对象与表示诊断，而不是继续解释事件。

低召回没有证明：

- 车辆在 SAR 中没有可见响应；
- 人眼连续审阅是错误的；
- 所有 8-bit 显示信息都无效；
- 光学先验或 SAR 局部结构路线整体无效；
- 需要回到 candidate bank、selector、ranking 或更复杂阈值树。

## 7. 为什么完整 GT 矩形不是可见响应 Mask

SAR GT 表示车辆身份与合理空间邻域，不表示每个框内像素都由车辆产生可见响应。框内同时可能包含：

- 当前暗的车体区域；
- 只在部分帧出现的响应；
- 背景弧线、竖线、热点或其他车辆邻域；
- 插值、稳定化和显示混合区域；
- 无法归属的弱边界。

用完整矩形作正 Mask 会把暗区和背景计为正；用完整矩形作可见响应分母又会把“没有显示响应的车体区域”计为漏检。RSA0 只允许 GT 确认身份、位置邻域、排除其他车辆、建立研究坐标和事后评价，不允许 GT 自动生成响应 Mask。

## 8. 为什么旧 robust-z、持久频率和固定核心不符合响应对象

- `robust-z` 只表达相对局部背景的亮度异常，弧线、竖线和固定热点同样可能高响应；弱但结构连续的车辆部件可能低于阈值。
- 像素持久频率假设同一稳定坐标像素长期承担同一语义，但车辆响应形态、宽度、端点和局部热点会随状态变化。
- 整窗固定 persistent core 把弱态、强态和局部结构变化压成静态交集，容易只留下最亮、最稳定的小子集。
- 以固定核心邻域限定 intermittent，会遗漏远离核心但仍与对象关系一致的间歇部件。
- 背景结构也可能比车辆响应更持久，因此“持久”不是车辆所有权。
- 对象应由骨架、局部区域、部件关系、时间连续性和背景反事实共同描述，而不是单一阈值或整窗频率图。

这些旧表示保留为待诊断通道和失败基线，不再作为默认响应真值生成器。

## 9. 为什么当前不能继续解释 birth、split、merge 和 migration

当基础响应对象只覆盖约 `2–3%` 的直接可见参考，组件的出现、消失和连接变化很大程度受阈值、分割碎裂、背景混入、稳定化误差和亮度变化控制。此时图上的一对多或多对一关系只能叫相关性事件，不能叫车辆物理响应动力学。

RSA0 只诊断哪些表示能稳定承载响应骨架、弱状态和背景排除。只有后续响应对象在多个窗口中被稳定恢复，并且事件对参考版本、表示和背景控制不敏感，才可重新申请 S1-D。

## 10. 为什么下一阶段研究对象必须是“车辆响应对象”

该对象同时容纳：

- 可确定的主响应骨架；
- 可确定和可能响应区域；
- 间歇出现的局部部件；
- 对象内部的方向、距离和邻接关系；
- 与背景结构的反事实对照；
- 无法强制归属的混合区域；
- 弱、中、强状态之间的变化。

它比完整框更接近实际显示事实，也比独立亮点或阈值连通片更接近人眼的连续判断。下一阶段种子—对象—传播方法只能从这种冻结对象语义出发。

## 11. 四类信息的角色

### 11.1 光学

- 确认物理车辆身份、光学可见区间和多车主体边界；
- 提供时间对应、粗方位、尺度范围和宽 search shell；
- 提供 optical proxy 条件坐标，检验表示能否在无目标 GT 时保留；
- 不判断 SAR 像素正负，不把 optical entry/exit 当车辆在 SAR 中的物理生灭。

### 11.2 SAR 灰度时序

- 提供实际显示域响应、背景结构和跨帧关系；
- 在光学先验内承担局部精定位所需的证据；
- 允许为空、间歇、混合或 unresolved；
- 不自行创建或切换物理车辆身份。

### 11.3 SAR GT

- 研究期确认车辆身份与合理邻域；
- 排除明显属于其他车辆的区域；
- 建立 `RESEARCH_ORACLE_COORDINATE_ONLY` 的研究坐标；
- 评价冻结表示和 atlas；
- 不进入部署推理，不自动生成正 Mask，不根据评价反向调表示或参考。

### 11.4 人工与多模态参考

- 通过连续 SAR、光学身份和 GT 上下文建立保守响应语义；
- 显式画出 scribble、skeleton、polygon、背景控制和 unresolved；
- 记录为什么归属、为什么排除及可能错误；
- 是研究期审阅与纠错机制，不冒充自动标注器或部署输入。

## 12. 继续保留的基础设施

- P0 固定 `24/50` 操作性时间契约及其假设边界；
- P1-E canonical vehicle registry、frame states 和 benchmark-only 标记；
- `2308×1334` fan display coordinate 与固定 `imaging_valid_mask`；
- 直接 SAR 显示像素坐标、源图哈希和输入 lineage；
- S1-LR2 的多背景共同场景运输和 holdout 验证思路；
- Raw/Smoothed GT 运动债务与 GT 仅作研究邻域的边界；
- inference、reference、evaluation 分入口以及先冻结后评价的工程隔离；
- Git 外大图/数组、Git 内小 manifest/脚本/报告/哈希的交付纪律；
- 直接视觉审阅与固定输入 replay。

## 13. 正式冻结的旧支线

以下内容只保留为历史基线，不再在原实现上调阈值或追加最小修复：

- S1X robust-z 恢复器、整窗 persistent core 和 symmetric weak maintenance；
- S1D0 v1.1 动态恢复器、生命周期状态机、inside-shell pre/post background、响应图和事件表；
- 旧轴对齐矩形 visible-response reference 与旧等面积基线结论；
- GM_RM011 压力失败和 GM_RM019 当前不可判定跨场景结果；
- candidate bank、Gate、selector、ranking、winner、最终框、自动标注和加权总分路线；
- 在响应恢复入口未通过前的物理动力学解释。

旧生命周期框架可作为光学身份准入/准出的历史基础设施保留，但 RSA0 不用它生成 SAR 正负参考，也不把 pre-entry/closed 同位置响应当背景。

## 14. RSA0 执行边界

### 14.1 允许

- 两个 GM_RM017 清晰短窗的 inventory、视觉包、直接审阅和响应 atlas；
- GM_RM019 的候选盘点与 mapping/reference debt 判定；
- 显示、结构和短时序表示的独立生成与评价；
- 研究期 GT 坐标、optical proxy 坐标和世界稳定坐标的明确分层比较；
- 非支配表示集合和下一阶段输入建议；
- 少量、语义明确的通道组合，但不形成总分。

### 14.2 禁止

- 完整生命周期恢复、三场景自动执行或 S1-D 动力学；
- 用 pre-entry/closed 生成背景阴性；
- GM_RM011 参与方法发现；
- 把 GM_RM019 的参考不足写成零召回；
- 完整车框、密实 Mask、自动标注、候选库、排序或 winner；
- 训练或大规模下载 VOS/分割模型；
- 根据 GT IoU、通道指标或可视化结果反向修改冻结 atlas；
- 把 validator PASS、文件数量或 commit 状态当科学成功。

### 14.3 顺序约束

1. Git、环境、数据和配置哈希冻结；
2. docs-only 语义冻结并推送；
3. 短窗 inventory 与视觉重建；
4. 连续审阅后选择关键帧；
5. 建立并直接审阅 atlas；
6. 冻结 atlas 和聚合哈希；
7. 生成表示；
8. 独立评价和非支配集合；
9. validator、正式六问报告、实现提交与推送。

不得在 atlas 冻结前根据参考计算通道优劣，不得在非支配集合形成前设计种子传播算法。

## 15. 停止条件

满足任一条件即停止表示扩展并报告数据/显示链债务：

- `GM_RM017:PV002 / 330–350` 在光学、GT 和连续 SAR 共同查看后仍无法形成一致主骨架；
- 两个清晰窗口都只能标出孤立最亮点，无法形成对象关系；
- 主响应与匹配背景在所有表示中不可区分；
- atlas 审阅者无法对确定响应、背景和 unresolved 达成内部一致；
- 当前 8-bit 显示域无法保留弱状态或结构连续性。

停止后应明确检查：原始幅度/功率、复数成像、固定灰度映射、成像配置、几何网格和 upstream 成像链。禁止用更多阈值或规则掩盖。

## 16. 对成熟方法的借鉴边界

RSA0 可以借鉴：

- scribble supervision 的高置信局部语义；
- seed expansion 的边界约束与局部扩展思想；
- interactive VOS 的多锚定帧和人工纠错；
- space-time memory 的多状态记忆；
- object-level memory 的部件关系与背景排除。

不可照搬：

- RGB 语义外观和自然图像密实轮廓；
- 单一首帧完整 Mask；
- 目标外观固定或每帧完整可见；
- 预训练 VOS 输出作为真值；
- 以模型安装、训练或下载替代基础 atlas 工作。

## 17. 本轮成功定义

RSA0 成功不要求完整 Mask。成功意味着：

- 至少两个车辆短窗有冻结、非矩形、包含骨架/背景/unresolved 的可信 atlas；
- 至少一组表示稳定覆盖主骨架；
- 至少一组表示能抑制主要背景结构；
- 弱态和强态都被独立检查；
- 至少部分能力在 optical proxy 坐标中保留；
- 下一阶段获得明确的冻结通道、关系和失败边界，而不是继续猜阈值。
