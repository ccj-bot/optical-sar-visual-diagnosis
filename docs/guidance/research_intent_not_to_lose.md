# Research Intent Not To Lose

Do not lose these research intentions:

- We are not moving the old pipeline into the new repository.
- We are not continuing to stack C1.5/C1.6 by inertia.
- We are not trying selector first.
- We are not trying to prove the current direction must be right.
- We must allow the single-point range prior to be overturned.
- We must allow the optical transfer representation itself to be found unsuitable.
- We must allow candidate generation to be biased by a wrong prior.
- We must allow temporal evidence to be found shallow or unused.
- We must allow GM_RM011 and GM_RM019 to require different handling.
- We must treat visualization as first evidence, not decoration.
- We must understand failure cases before writing algorithms.

The repository should preserve uncertainty until visual review and accounting evidence justify narrowing it.
