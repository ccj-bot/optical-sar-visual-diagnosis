# OTY2 长期研究记忆

更新时间：2026-07-19

## 使用规则

后续 OTY2 局部结构、跨帧关系或粗定位任务必须先读本文件，再读：

1. `OTY2_FAILED_HYPOTHESES_AND_PITFALLS.md`
2. `OTY2_OPEN_PHYSICAL_AND_METHOD_QUESTIONS.md`
3. `OTY2_EXPERIMENT_LEDGER.md`
4. `../OTY2_SESSION_START_HERE.md`

本文件只冻结被真实图像、已运行实验和来源审计支持的事实。研究期 GT 可以用于事后验证和坐标审计，但不能被回写成运行时输入。

## 已支持事实

### F1. 三场景是静止车辆、移动平台的多视角成像问题

- GM_RM011、GM_RM017、GM_RM019 中车辆世界位置和航向固定，变化来自平台自运动和成像投影。
- 旧文档中的“车辆运动、轨迹、进入和退出”只能解释为观察生命周期或平台经过诱导的表观变化。
- 适用边界：当前最终光学/SAR 图像域；不等于完整成像前传感器链已经恢复。

### F2. 当前 SAR 显示扇极坐标和固定显示网格可用于研究期几何审计

- 最终 SAR 灰度画布为 `2308 x 1334`，共享扇形原点约为 `(1154.0, 1330.6)`。
- `0.03 m/px` 可作为当前重建显示网格尺度，用于局部长度和间距表达。
- 它不是 3 cm 独立物理分辨率，也不允许把整幅 SAR 当作均匀二维米制平面。

### F3. 光学横向顺序可提供宽方位与同帧多车排他约束

- 已审阅 GM17 和 GM11 多车窗口中，光学左右顺序与 SAR 方位顺序保持一致。
- 该关系可排除部分邻车交换，并可用于宽方位壳。
- 适用边界：定性顺序和宽方位；不能宣称跨场景精确二维中心映射。

### F4. 光学侧视长轴能排除明显 90 度错误方向

- 清晰近水平侧视可排除同中心近竖直方向控制。
- 原 rotated-box `angle` 不是无条件长轴方向；当 `height > width` 时必须把长轴语义旋转 90 度后再规范化。
- 适用边界：粗方向排除；不能单独决定精确 SAR GT 角度或响应边界。

### F5. 截断不是信息全部消失

- 左、右、底部截断必须分开记录。
- 截断帧仍可保留可见长轴、端部、未截断维度、边界交接、尺度趋势和多车顺序。
- 边界解除只提供最近通过候选 bracket，不等于精确最近点。

### F6. GM17 高 alpha 侧视存在原始灰度直接可见的车辆关联近距侧结构

- GM17 PV002/PV003/PV004 中，车辆尺度、沿无向长轴 `u` 分布、位于朝向扇形原点的 `+v` 侧的碎片带和热点在原始灰度中可见。
- 它不依赖单一高通 sigma；sigma 只用于描述性增强。
- 同车连续线程中，结构会扩展、增强、收缩、偏移、分裂、弱化和端点失衡。
- 适用边界：当前 GM17 高身份、有效区内部、侧视主导线程；不能外推到近端视或跨场景。

### F7. 固定像素模板不成立，部件角色级谱系更合适

- 车辆坐标对齐没有稳定提高整块像素相关。
- 相邻帧不是同一模板复制，而是对同一潜在响应关系的互补观察。
- 允许追踪的是“近距侧带、热点/短段、背景交叉”等角色及其状态变化，不是固定像素或同一物理散射点。

### F8. GM17 三个世界注册空道路控制没有稳定复制车辆侧锁定

- R2A 的道路控制削弱了“近距侧带纯粹来自固定道路”的主要解释。
- 道路、扇形弧、径向强线、无效区边界仍是局部竞争因素。
- 车体与车辆-地面交互尚不可分，不能把近距侧带称为纯车体部件。

### F9. GM11 近原点和 GM19 稀疏/截断案例当前不可辨识

- GM11 可见径向强线、扇形弧和边界结构，真实区与控制区同样丰富。
- GM19 同帧 GT、身份和连续可见性不足，不能建立可靠部件谱系。
- 正确状态是 `NOT_IDENTIFIABLE`，不是“没有车辆响应”或“机制被否定”。

### F10. G1 已留下一个目标 GT 未访问的 GM17 宽局部入口

- `oty2_rsa2_g1_forward_frozen_geometry_intervals.csv` 的 GM17 PV002 SAR 321/342 区间在揭示目标 GT 前冻结。
- 它可以作为本轮 L1 条件化局部提取的中心壳入口，再按冻结车辆尺寸范围扩展为宽窗口。
- 它仍是 GM17 场景内开发关系，不是一般性 L2 粗定位闭环。

### F11. 受限 GM17 侧视 L1 局部结构提取能力已经建立

- 本轮程序只读取 G1F0002 冻结 forward shell、原始 SAR、相邻帧、扇形 Mask、粗方向和尺寸范围。
- 运行期没有读取当前目标 SAR GT 中心/框、人工 NSB 折线、已知峰位或历史 `0.65-0.79` 峰区间。
- 多尺度 DoG/Frangi、LSD、碎片图连接、近原点侧关系、热点附着和多帧持续共同输出带中心线、附着热点与不确定状态。
- 一个结构图连通组覆盖 SAR `339/341/342/343/344/347/348/349` 八帧；每帧允许同一厚带分裂成一到两条中心线，不产生唯一中心或 winner。
- 隐藏卡事后审计中，SAR 339 的 2 条主带有 1 条接触人工 NSB，SAR 344 的 2 条主带均接触人工 NSB。
- 世界注册空道路 RC1/RC2/RC3 在相同多帧准入下均无时序支持主带。
- 能力边界：`L1_CONDITIONED_LOCAL_EXTRACTION`，仅限 GM17 侧视主导、G1F0002 宽壳邻域；不构成一般 L2、L3、最终框或自动标注。

## 当前可冻结的物理关系

1. 静止车辆、多视角平台经过是主因果模型。
2. 扇极显示坐标、宽方位顺序、粗方向排除、车辆尺度范围和有效区 Mask 可用于研究期结构实验。
3. 高 alpha 侧视下，近距侧长轴带是车辆存在相关的部件角色，但责任为 `VEHICLE_ASSOCIATED_BODY_GROUND_MIXED`。
4. 多帧应表达角色重组和背景反证，不应退化为平均、最大值或固定模板。

## 当前不能外推

- 不能把 GM17 的近距侧带外推为所有姿态或所有场景的统一结构。
- 不能把人工部件卡、开放折线或 GT 框当作响应 Mask。
- 不能把统计可分写成物理因果。
- 不能把 G1 的 GM17 区间写成跨场景部署映射。
- 不能把多模态可观察性直接写成程序已可提取。
- 不能由单一阈值、单一峰值或单一增强尺度决定结构存在。

## 能力阶梯状态

- 已有能力：GT 开卷的局部结构描述、背景反证、姿态条件化语法和有限跨帧角色谱系。
- 当前能力：已建立受限 GM17 侧视 L1，输出带中心线、附着热点、跨帧图和失败状态。
- 下一瓶颈：将入口从单一 G1F0002 冻结壳扩展到一般无目标-GT粗搜索区，并验证中间 alpha 与非 GM17 场景。
