# OTY2 开放物理与方法问题

更新时间：2026-07-19

只保留真正未解决、会改变下一步能力路线的问题。

## P0 最高优先级

### Q1. 多模态教师的观察是否依赖坐标、历史术语或 GT 暗示？

- 需要比较局部、全局、邻帧、有/无坐标、有/无“近距侧带”文字提示。
- 必须记录道路误选和 `NOT_IDENTIFIABLE` 能力。
- 当前 Codex 同会话复核不等于独立模型重复，结论必须标注工具限制。

### Q2. 受限 L1 如何从单一 G1F0002 扩展？

- 当前只在 GM17 侧视主导、G1F0002 宽壳邻域闭环。
- 需要在 G1F0001 中间 alpha 和至少一个非 GM17 可辨识线程上冻结参数后复现。
- 必须继续使用世界注册道路控制和 `NOT_IDENTIFIABLE` 输出。

### Q3. 程序在未闭环案例中首先失败在哪一层？

- 候选生成：看不到原始灰度中的带/热点。
- 结构连接：候选存在但无法组成车辆尺度开放结构。
- 背景判别：车辆与道路/扇形长线不可分。
- 局部入口：没有目标 GT 时宽窗口无法覆盖真实区域。

## P1 高优先级

### Q4. 多帧关系能否降低单帧背景误触发？

- 需要允许片段出现、分裂、合并、偏移和消失。
- 不得把相邻帧当作独立重复，也不得用简单最大值/均值制造稳定 Mask。

### Q5. G1 的 GM17 宽壳是否足以承担受限 L2，还是只够做单案例 L1？

- SAR 321/342 是目标 GT 未访问时冻结的有界案例。
- 需要检验壳扩展后是否保留目标结构，并量化是否同时引入邻车和道路竞争。
- 跨场景和截断状态仍未闭合。

### Q6. 近距侧带中车体与车辆-地面交互能否进一步分离？

- 当前数据没有极化、复数相位或独立地面条件控制。
- 在仅有灰度和多视角时，可能只能保留混合责任。

## P2 数据条件问题

### Q7. 一般姿态语法需要的最小补充数据是什么？

- 至少一条非 GM17、有效区内部、高身份、usable/gold、背景不过度支配的连续斜视或近端视线程。
- 完整 0-90 度转换还需要同一车辆覆盖更宽 alpha，而不是跨场景拼接。

### Q8. 独立多模态教师重复需要什么工具？

- 至少两个相互独立的视觉模型调用或隔离会话，使用冻结图板和统一输出 schema。
- 当前若只能由同一 Codex 会话复核，必须把它写成同模型重复审阅，而非独立教师一致性。

## 冻结不再开放的问题

- 是否存在静止车辆/移动平台主因果模型：已冻结。
- 原 rotated-box angle 是否可直接当长轴：已否定。
- 单一高通尺度是否定义结构：已否定。
- 三个世界注册空道路是否稳定复制 GM17 车辆侧锁定：未复制，纯道路主解释已削弱。
- GM17 近距侧带是否可外推为全局规则：当前禁止。
- 冻结 G1F0002 宽壳内能否输出明确结构对象：已建立受限 L1；输出是带中心线/热点结构图和不确定集合，不是唯一中心或 Mask。
