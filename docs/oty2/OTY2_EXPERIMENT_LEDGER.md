### 外部方法入口

1. Tan et al., 2018, *Target Recognition of SAR Images via Matching Attributed Scattering Centers with Binary Target Region*, DOI `10.3390/s18093019`。
   - MSTAR 高分辨率目标识别，传感器条件与本毫米波近场灰度扇形成像不完全相同。
   - 需要 ASC 模型/模板，本项目当前没有。
   - 启发：点峰应升级为带属性的区域/结构，不应直接把最亮点当车辆。
   - 最小转化：输出每个片段的方向、长度、宽度、亮度和不确定责任。
2. Araujo et al., 2022, *Non-Cooperative SAR ATR Based on Scattering Centers Models*, DOI `10.3390/s22031293`。
   - 依赖合成训练模型和散射中心假设检验，本项目不具备同类训练条件。
   - 启发：候选生成和假设验证应分离；背景反证要进入验证层。
3. Pei and Bao, 2005, *Multi-aspect radar target recognition method based on scattering centers and HMMs classifiers*, DOI `10.1109/TAES.2005.1541451`。
   - 多视角雷达序列与本项目跨帧状态问题相容，但任务是分类、不是局部提取。
   - 启发：允许散射中心角色随视角转移，用状态序列而非固定模板。
4. Frangi et al., 1998, *Multiscale vessel enhancement filtering*, DOI `10.1007/BFb0056195`；`scikit-image 0.26` 提供正式实现。
   - 不是 SAR 专用，但适合多尺度亮脊候选生成。
   - 风险：道路/扇形长线同样会高响应，必须加长度穿越和背景控制。
5. von Gioi et al., 2010/2012, LSD, DOI `10.1109/TPAMI.2008.300` / `10.5201/ipol.2012.gjmr-lsd`。
   - 无需针对图像调参并带 a-contrario 假警控制，适合输出显式线段。
   - 风险：散斑和长道路线会产生候选，必须与亮脊、方向先验和多帧关系联合。

### 首轮选择

首轮选择路线 B 与 A 的最小组合：先冻结无 GT 教师图板和观察 schema，再实现经典候选提取。理由是教师条件依赖和程序候选层必须使用同一批输入，否则两条路线无法直接比较。输出教师结果只标记为 `RESEARCH_TEACHER_OUTPUT_NOT_GT_NOT_MASK`。

### GT 边界

- 运行输入：G1 目标 GT 未访问的 forward interval、原始 SAR、相邻帧、扇形原点/Mask、冻结方向和尺寸范围。
- 禁止运行输入：当前目标 GT 中心/框、人工 NSB 折线、已知峰位、`0.65-0.79` 搜索阈值。
- posthoc：实验冻结后才允许叠加 GT 和人工卡，测量结构关系与失败原因。

## Cycle 1：多尺度候选生成与无提示教师图板

- 假设：Frangi/DoG/LSD 在 G1F0002 宽壳中可以直接产生车辆相关结构对象。
- 候选实验：A1 多尺度脊线+线段；B1 无 GT 教师图板条件消融。
- 选择理由：同一批输入可直接比较“模型看见什么”和“程序生成什么”。
- 实际运行：8 个 GM17 SAR 帧，7 张教师图板。
- 真实图像观察：下部近水平亮带在无提示单帧中可见，但所有权不明确；相邻帧中持续重组；道路与上方弧线竞争明显。
- 结果：程序输出 1562 个对象、10101 条图边，形成线段/热点汤。
- 否定：各向同性扩张 G1 中心壳不能作为车辆结构窗口。
- 能力增量：失败定位到宽壳表示与结构连接，而不是候选完全缺失。
- 决策：修复表示，不继续调单一阈值。

## Cycle 2：车辆轴各向异性窗口与带中心线组装

- 假设：按冻结长短轴范围扩展中心壳，并将共线碎片组装成带，可把对象汤压缩为显式结构。
- 候选实验：A2 各向异性支撑；D1 碎片图连接。
- 实际运行：加入带中心线和附着热点输出。
- 真实图像观察：SAR 344 的一条程序带进入人工 NSB 区域，但远距平行长线仍被保留。
- 结果：显式带对象建立，背景责任仍未闭合。
- 能力增量：从像素/碎片集合升级为开放带中心线和热点图。
- 决策：加入近原点侧关系与热点附着，不以方向一致作为充分条件。

## Cycle 3：近原点侧关系、热点附着与单帧道路控制

- 假设：相对中心壳的近原点侧关系和带内热点支持可排除远距平行背景。
- 实际运行：使用径向关系而非历史峰位；把未附着热点降为不确定。
- 真实图像观察：GM17 目标侧带被保留；RC2/RC3 单帧纹理仍可拼出假带。
- 结果：单帧关系不足以拒绝所有道路/散斑结构。
- 能力增量：定位最后失败点为跨帧背景判别，而非候选或局部连接。
- 决策：最后一轮切换到多帧持续，不再调整单帧阈值。

## Cycle 4：多帧带图与世界注册道路控制闭环

- 假设：车辆关联带在短窗中持续/重组，世界注册空道路的单帧假带不形成同等持续关系。
- 实际运行：GM17 SAR `339/341/342/343/344/347/348/349`；RC1/RC2/RC3 在 SAR `341/342/343/347/348/349` 的逐帧注册位置。
- 运行输入 GT：否；只用 G1F0002、原始/相邻 SAR、扇形 Mask、粗方向和尺寸范围。
- 真实图像观察：一个结构图连通组覆盖 8 个 GM17 帧；厚带在部分帧分裂为两条中心线。道路控制在最终时序准入下均无主带。
- posthoc：SAR 339 主带 2 条中 1 条接触人工 NSB；SAR 344 主带 2 条均接触人工 NSB。
- 多模态重复性：同一 Codex 会话两次审阅均在 T01/T03/T05 指出下部带及其碎片化变化；T06 道路控制未出现同等拓扑；T07 正确保持 `NOT_IDENTIFIABLE`。没有独立第二视觉模型，不能宣称跨模型重复。
- 支持：受限 GM17 侧视 L1 已建立。
- 未解决：带的唯一物理归属、厚带内部中心线合并、中间 alpha 程序闭环、非 GM17 泛化和一般 L2 粗定位。
- 能力增量：输出带中心线、附着热点、跨帧图、道路拒绝和失败状态。
- 最终决定：`Result A`，能力级别 `L1_CONDITIONED_LOCAL_EXTRACTION`。
