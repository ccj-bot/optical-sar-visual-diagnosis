# 光学时序辅助 SAR 自动标注：研究路线复位记录

**日期：** 2026-07-13<br>
**用途：** 作为后续 Codex Session、研究分支与阶段任务的最高层路线依据。<br>
**适用项目：** 光学时序辅助毫米波 SAR 自动/半自动标注<br>
**当前主分支建议：** `feature/oty2-data-foundation-and-global-identity`

---

## 1. 研究路线为什么需要复位

近期研究并非完全没有积累，但整体推进出现了明显失衡：

- 大量时间投入在检测器比较、跟踪器参数、候选框、Gate、selector、ranking 和综合统计；
- 同步、身份、坐标、映射等基础事实没有先冻结；
- 光学完整时序流提供的强信息没有得到充分利用；
- 多车竞争被处理成逐帧局部门限问题，而不是整段时间流上的全局分配问题；
- SAR 图像中的车辆被过度压缩为灰度、能量、质心、占用率等统计量；
- 尚未建立统一的米制坐标、有效成像 Mask、车体规范坐标和结构化散射表示；
- 工程产物、报告、CSV、阶段编号较多，但能够直接支撑 SAR 自动标注的科学闭环较少。

因此，项目必须从“继续增加 Gate 和候选规则”转回到以下顺序：

> 数据资产与同步<br>
> → 光学全局同车身份<br>
> → 方位映射与 SAR 坐标<br>
> → 连续优质 GT 车辆线程<br>
> → SAR 车体结构化表示<br>
> → 视角条件下的散射结构动力学<br>
> → 完整时序联合标注<br>
> → 全时间流验证

---

## 2. 研究问题的重新定义

旧问题经常被表述为：

> 在一个光学映射区域内，利用若干统计特征和 Gate，从候选池中选出一个 SAR 框。

该定义过于局部，也过度依赖逐帧判断。

新的核心问题应定义为：

> 已知完整光学时间流中同一辆物理车辆的身份、运动、姿态和方位轨迹，在更高帧率的米制 SAR 时间流中恢复一个随相对观测角变化的车辆散射结构状态，并由该状态的完整时序包络生成可靠标注。

真正的研究对象不是单帧光学框、单帧 SAR 框或某个候选，而是：

> **同一辆物理车辆在光学时间流和 SAR 时间流中的联合状态轨迹。**

可以将车辆状态抽象为：

\[
Z_t =
\{
\text{车辆身份},
\text{位置},
\text{车体方向},
\text{尺寸},
\text{可见性},
\text{截断/遮挡状态},
\text{SAR 散射结构}
\}
\]

其中：

- 光学时间流主要提供身份、运动、外观、可见性、姿态和进入/退出信息；
- SAR 当前帧提供车辆响应与背景响应；
- SAR 前后帧提供结构演化信息；
- 最终标注是联合推断结果，而不是逐帧候选选择结果。

## 3. 必须区分的三类内容

后续所有文档、脚本和报告必须明确区分以下三类信息。

### 3.1 已确认事实

指已经由原始资产、配置、日志、可重复脚本或人工复核直接确认的信息。

例如：

- 某场景光学帧数；
- 某场景 SAR 灰度帧数；
- 图像尺寸；
- 帧号是否连续；
- 光学视频标称帧率；
- SAR 灰度视频标称帧率；
- 某个完整车辆线程的人工身份结论。

### 3.2 项目操作性冻结假设

指缺少独立硬件证据，但为了继续研究而由项目负责人明确采用的统一契约。

例如：

- 光学 frame 0 与 SAR frame 0 作为共同时间原点；
- 相机和雷达在当前阶段近似共位置；
- SAR 灰度流作为权威时间轴；
- 光学到 SAR 方位向映射在通过留出验证后冻结。

操作性假设必须明确标注为假设，不能伪装成已经获得公共时钟或严格外参标定证明。

### 3.3 尚待后续审计的问题

例如：

- 原始 ADC/IQ 是否仍可获取；
- 是否存在复数成像矩阵；
- GM_RM019 伪彩视频时间基冲突；
- SAR 米制坐标和有效成像 Mask 的唯一来源；
- 历史记录中所述 231 行资产是否存在。

这些问题需要继续核验，但不能无条件阻断所有后续阶段。

## 4. 数据资产与硬同步原则

### 4.1 完整时间流优先

不得继续使用稀疏审阅样本反推完整采集同步关系。

必须明确区分：

1. 原始完整光学时间流；
2. 原始完整 SAR 时间流；
3. 稀疏 GT 审阅样本；
4. 已有光学—SAR 配对表；
5. 同一物理车辆线程。

审阅样本是评价和诊断锚点，不是完整同步事实源。

### 4.2 当前同步契约

当前项目采用：

- 光学时间轴：24 fps；
- SAR 权威时间轴：灰度 SAR 的 50 fps；
- 同一场景中，光学 frame 0 与 SAR frame 0 作为共同时间原点；
- 采用固定采样率建立全帧配对；
- 不设置逐样本软同步分数；
- 不使用 GT、IoU 或后验标注结果反向调整时间偏移。

时间关系为：

\[
t_o(i)=i/24
\]

\[
t_s(j)=j/50
\]

对于任意 SAR 帧 \(j\)，可找到其对应的光学左右邻帧及插值比例。

该契约属于：

> **项目操作性冻结假设**

不是公共硬件时间戳证明。除非后续发现直接反例，否则不再逐帧估计同步偏移。

### 4.3 同步问题的正确边界

后续只需继续检查：

- 中途是否丢帧；
- 是否存在重复帧；
- 尾部是否多录或少录；
- 灰度 SAR 与伪彩 SAR 是否按帧号一一对应；
- 视频封装元数据是否与实际帧序列一致。

不应重新引入：

- 每帧同步 Gate；
- 样本级时间可信度；
- GT 驱动偏移修正；
- 不同窗口单独寻找最优偏移。

## 5. 光学侧的正确任务：全局物理车辆身份统一

在固定相机、连续视频、几十毫秒帧间隔下，车辆的以下信息不会无规律改变：

- 颜色；
- 纹理；
- 车型轮廓；
- 车窗与车灯结构；
- 长宽比例；
- 姿态变化趋势；
- 运动方向；
- 尺度变化；
- 进入和离开视场的位置。

因此，光学同车统一不应长期依赖大量局部 Gate。

### 5.1 跟踪器的正确地位

可以引用并使用成熟方法，例如：

- ByteTrack；
- BoT-SORT；
- OC-SORT；
- StrongSORT；
- 最小费用流；
- 多假设跟踪；
- 图匹配；
- 轨迹片段全局关联。

但跟踪器只负责生成初始短轨迹或局部关联，不应直接把 tracker ID 当成物理车辆身份。

### 5.2 全局离线视角

本项目不是实时在线跟踪任务。

因此可以使用完整过去帧和未来帧，从“上帝视角”统一判断：

- 哪些短轨迹属于同一辆车；
- 哪些目标只是短时遮挡；
- 哪些检测框发生了主体切换；
- 哪些车辆离开后不应重新连接；
- 哪些新目标确实是新进入车辆。

### 5.3 多车竞争的正确表达

多车竞争不应主要由以下方式处理：

- 距离小于某阈值就连接；
- 颜色差大于某阈值就拒绝；
- 面积变化过大就切断；
- 某个框分数低就退出。

更合理的状态模型是：

\[
\text{视场外}
\rightarrow
\text{准入}
\rightarrow
\text{稳定跟踪}
\rightarrow
\text{遮挡}
\rightarrow
\text{恢复}
\rightarrow
\text{准出}
\]

核心规则包括：

- 每个检测在同一帧最多属于一辆物理车辆；
- 每辆物理车辆在同一帧最多有一个主体观察；
- 车辆可以短时无框但保持身份；
- 新身份必须有合理的进入解释；
- 旧身份结束必须有合理的退出或长期不可见解释；
- 多条候选关联应在整段时间流上全局竞争。

这是一种全局排他分配问题，而不是局部 Gate 树。

### 5.4 光学颜色的正确使用

光学颜色不能直接证明 SAR 响应属于车辆，但可以且应当用于：

> 光学时间流中的同车身份统一。

必须区分：

- 光学颜色不能作为 SAR 散射证据；
- 光学颜色可以作为光学车辆身份强证据。

## 6. 方位向映射原则

方位向映射属于基础标定，不应针对每个失败样本反复调整。

### 6.1 标定锚点选择

应选取：

- 光学中车辆完整可见；
- 非边界截断；
- 同车身份可靠；
- SAR GT 框质量较好；
- 覆盖多个方位位置；
- 尽可能覆盖不同车辆和不同时间段。

### 6.2 映射验证

建立：

\[
x_{\text{optical}}
\rightarrow
\theta_{\text{SAR}}
\]

或：

\[
x_{\text{optical}}
\rightarrow
x_{\text{SAR,metric}}
\]

验证必须按物理车辆划分，而不是随机按帧划分。

需要检查：

- 是否存在系统偏差；
- 不同场景是否需要独立映射；
- 图像左右端是否存在非线性；
- 误差相对于车辆尺度是否可接受；
- 完整车辆与截断车辆残差是否不同。

### 6.3 冻结原则

如果映射误差已经稳定小于车辆结构尺度，则冻结。

后续不得因为某些 SAR 候选或 GT 结果不好，就重新调整方位映射。

光学方位信息可作为较强约束：

> 光学决定车辆在 SAR 方位向的大致位置。

但光学框宽度不能直接复制为 SAR 框宽度。

---

## 7. 相机与雷达共位置假设

当前阶段采用：

- 相机与雷达观察原点近似共位置；
- 两者物理间距相对于车辆距离较小；
- 小平移误差暂时忽略；
- 水平视轴差异由经验方位映射吸收；
- 暂不进行严格三维外参投影。

该假设属于项目操作性冻结假设。

未来如获得可靠外参标定，可更新；当前不应将外参不确定性变成每帧调节变量。

## 8. SAR 图像域必须建立唯一物理坐标

每张 SAR 图不能只被视为 PNG 数组，而应被定义为带物理坐标的响应场：

\[
I_t(X,Y)
\]

其中：

- \(X\)：方位向或场景横向米制坐标；
- \(Y\)：距离向米制坐标；
- 雷达原点明确；
- 坐标轴方向明确；
- 每个像素对应的物理位置明确；
- 有效成像区域明确。

### 8.1 像素网格与真实分辨率必须区分

如果当前图像网格约为：

\[
0.03\ \text{m/pixel}
\]

只能说明图像坐标采样间隔约为 3 cm。

不能直接宣称 SAR 真实空间分辨率为 3 cm。

必须区分：

- 像素网格间距；
- 成像点扩散函数；
- 实际距离分辨率；
- 实际方位分辨率。

### 8.2 必须确认图像网格类型

需要明确当前 SAR 图属于：

1. 笛卡尔米制网格；
2. 距离—角度网格；
3. 扇形显示后重采样网格。

只有确认是笛卡尔米制网格，才能直接使用固定米/像素。

### 8.3 Mask 语义必须拆分

至少区分：

- `imaging_valid_mask`：成像有效区域；
- `gt_box_region`：GT 框区域；
- `vehicle_response_mask`：车辆响应支撑；
- `intensity_threshold_mask`：强度阈值显示区域；
- `registration_valid_mask`：规范化后的有效像素；
- `occlusion_or_boundary_missing_mask`：遮挡或边界缺失区域。

这些概念不得继续混用。

## 9. 必须审计 SAR 信息层级

数据资产审计必须确认是否存在：

- 原始 ADC；
- 原始 IQ；
- 距离压缩结果；
- 慢时间或孔径维数据；
- 复数 SAR 成像矩阵；
- 幅度图；
- 功率图；
- 灰度图；
- 伪彩图。

信息优先级为：

> 复数成像结果（如存在）<br>
> → 原始幅度或功率图<br>
> → 灰度显示图<br>
> → 伪彩图仅用于显示或固定派生特征

需要明确：

- 二维成像结果蕴含了距离、孔径、视角和散射中心叠加后的结构；
- 如果只剩灰度幅度图，不能声称恢复已丢失的相位信息；
- 伪彩图不是新的物理观测维度。

## 10. SAR 车辆必须采用结构化表示

车辆不能继续被压缩为：

- 平均能量；
- 最大值；
- 占用率；
- 质心；
- 碎裂度；
- 若干加权统计分数。

这些量可以作为辅助描述，但不能代表车辆散射结构本身。

### 10.1 第一层：车体规范响应场

对于同一车辆 \(k\)，建立：

\[
A_{k,t}(u,v)
\]

其中：

- \(u\)：车体长轴方向；
- \(v\)：车体短轴方向；
- 每帧统一平移和旋转到车体坐标；
- 雷达方向也变换到车体坐标；
- 保留原始强度；
- 保留有效 Mask；
- 保留物理尺度。

### 10.2 第二层：散射结构元素

从响应场中提取：

- 紧凑散射中心；
- 延展亮脊；
- 侧边响应；
- 端部响应；
- 角点响应；
- 弱支撑区域；
- 多个散射中心组合；
- 固定背景线状结构。

单个结构元素可表示为：

\[
q_n =
\{
\text{位置},
\text{强度},
\text{尺度},
\text{方向性},
\text{形状},
\text{持续性},
\text{近侧关系}
\}
\]

元素之间还应表示：

- 平行；
- 共线；
- 对称；
- 位于车体端部；
- 位于近雷达侧；
- 共同运动；
- 此消彼长；
- 分裂或合并。

因此，单帧车辆应表示成：

> **散射结构图**

而不是一个统计向量。

### 10.3 第三层：结构状态轨迹

对于同一辆车，建立：

\[
\mathcal{S}_k(u,v,\alpha,r,t)
\]

其中：

- \(u,v\)：车体坐标；
- \(\alpha\)：相对观测角；
- \(r\)：车辆与雷达距离；
- \(t\)：时间；
- 内容为响应场或散射元素状态。

研究重点包括：

- 哪些结构持续存在；
- 哪些结构沿近雷达侧迁移；
- 哪些结构增强或减弱；
- 哪些结构发生主导切换；
- 哪些结构分裂或合并；
- 哪些结构在临界角度突然出现或消失；
- 哪些结构固定在世界坐标中，因此属于背景；
- 哪些结构随车辆共同运动。

## 11. 高维表示不等于黑箱特征向量

不能将“更高维结构表示”简单替换为：

> 将 SAR 裁剪送入神经网络，得到一个 256 维 embedding。

正确顺序是：

1. 建立米制坐标；
2. 建立车体规范坐标；
3. 保留散射结构元素；
4. 建立元素间空间关系；
5. 建立连续视角下的状态转移；
6. 再考虑集合网络、图神经网络或时序模型。

学习模型的输入应当是：

> 具有物理坐标和结构关系的响应场序列或散射元素集合。

而不是缺少解释的灰度裁剪。

## 12. GT 的正确使用方式

应选取一批“黄金车辆线程”，满足：

- 光学身份明确；
- 光学车体大部分时间完整；
- SAR GT 框连续；
- 同一目标在不同姿态和观测角下有足够帧；
- 背景相对可解释；
- GT 框质量稳定；
- 具有连续 SAR 响应。

黄金线程用于：

1. 标定光学—SAR 方位映射；
2. 确认 SAR 米制坐标；
3. 建立车体规范响应场；
4. 发现散射结构；
5. 研究结构随视角变化；
6. 建立状态转移模型。

必须按物理车辆划分：

- 标定线程；
- 机制发现线程；
- 留出验证线程。

不能把同一辆车的一部分帧用于发现，另一部分帧用于宣称泛化。

GT 是研究和评价工具，不得成为运行时选框依据。

## 13. 最终标注应为整段时序联合推断

本项目不是实时在线任务，因此不应逐帧贪心选择候选。

应对同一辆车完整经过视场的时间段联合求解：

\[
\hat Z_{1:T}
=
\arg\max_{Z_{1:T}}
\left[
\sum_t O_t(Z_t)
+
\sum_t D_t(Z_t,Z_{t+1})
+
C_{\text{optical}}
+
C_{\text{identity}}
\right]
\]

其中：

- \(O_t\)：当前 SAR 帧的结构观察证据；
- \(D_t\)：相邻帧的散射结构状态转移；
- \(C_{\text{optical}}\)：光学身份、方位、姿态和可见性约束；
- \(C_{\text{identity}}\)：车辆准入、遮挡、恢复和退出逻辑。

### 13.1 少量硬约束

只保留必要硬约束：

- 时间顺序；
- 一对一身份分配；
- 有效成像 Mask；
- 不可能的空间跳跃；
- 不可能的车辆尺度变化；
- 物理车辆不能同时占据互斥状态。

### 13.2 统一软证据

软证据包括：

- 光学颜色、外观和运动；
- 光学姿态与完整性；
- 方位映射残差；
- SAR 主体结构；
- 车辆尺度；
- 散射元素共同运动；
- 视角条件下的结构转移；
- 固定背景惩罚；
- 前后帧支持。

最终车辆框应由：

> 整段时间流中恢复出的车辆散射支撑取物理包络

而不是从候选池中选择最高分框。
