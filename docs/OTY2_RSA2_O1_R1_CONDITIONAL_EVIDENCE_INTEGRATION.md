# OTY2-RSA2-O1-R1 有条件证据联合修订

日期：2026-07-18

阶段：OTY2-RSA2-O1-R1 Conditional Evidence Integration Clarification

性质：对 O1 “禁止推导”措辞的条件化解释修订；不修改 O1 的实体、证据层、未知状态和算法禁令。

## 1. 修订目的

O1 正确禁止把光学存在、GT 几何、跨帧相似、高频响应或 tracker ID 等单一较弱证据无条件升级为更强科学结论。但“各状态不能互相推出”容易被误读为：不同模态、不同状态和不同时间尺度不能共同压缩解释空间。

这种误读会再次把完整时序、光学身份、物理尺度、多车排他和背景生命周期降格为无作用信息，与深度错误复盘的纠偏方向冲突。

本修订将原表述明确为：

> 任何单一较弱状态都不能被无条件等同或自动升级为更强状态；多个来源相对独立的证据，可以在明确记录反证、适用边界和残余未知的前提下，联合支持更强解释。

## 2. 保持不变的 O1 边界

以下 O1 冻结继续有效：

- PhysicalVehicle 是跨帧持续实体，SARLocalResponseInstance 只属于当前帧；
- DIRECT_OBSERVATION、RELATION_INFERENCE、UNKNOWN 必须分层；
- 光学身份不等于 SAR 像素所有权；
- GT 框不等于车辆响应 Mask；
- 多帧互补不等于并集、交集、最大值或完整对象；
- P1/P2/P3 不等于跨帧物理部件；
- 0.03 m/px 是有效重建网格尺度，不是 3 cm 独立分辨率；
- 背景结构、多车排他、GT 缺口和身份冲突必须显式保存；
- 不授权检测器、阈值、评分、排序、selector、winner、Mask、传播、自动身份修正或自动标注。

## 3. 四种证据关系

### 3.1 直接决定

单一证据本身足以确定一个较弱、局部事实。

| 证据 | 可直接决定 | 仍不能决定 |
| --- | --- | --- |
| 原始 SAR 中直接看到局部响应 | sar_local_response_observed | 唯一车辆所有权、完整边界 |
| usable/high GT | 当帧研究期 sar_geometry_known | 框内所有响应归属、部署期位置 |
| 光学帧直接看到车辆 | optical_vehicle_present 与可见状态 | SAR 中心、响应 Mask |
| 车辆退出后固定竖线仍存在 | 该结构在退出后仍持续 | 每个混合像素的精确背景贡献 |

直接决定只在该证据实际覆盖的帧、区域和质量范围内成立。

### 3.2 提供约束

证据不能单独决定归属，但可以排除或缩小解释。

| 证据 | 约束作用 | 不得偷换为 |
| --- | --- | --- |
| 光学身份与完整生命线 | 约束车辆何时存在、进入、退出、遮挡和恢复 | SAR 像素所有权 |
| GT 或部署期可获得的几何先验 | 约束合理位置、尺度、方向和移动量级 | 精确响应边界 |
| 多车顺序与同帧排他 | 约束一个响应不能同时属于互斥车辆 | 自动唯一分配 |
| 背景退出后持续 | 反驳该稳定结构只属于已退出车辆 | 自动背景 Mask |
| 相邻帧与短窗 | 约束非物理突跳、支持互补或替代显现 | 固定散射部件持续 |
| 中窗和完整生命周期 | 约束车辆坐标量级、主体切换和错误延续 | temporal score |

### 3.3 联合支持

多个来源相对独立的证据可以共同支持更强但仍有边界的解释。

sar_response_attribution_supported 的联合证据责任至少包括：

1. 原始 SAR 中存在可直接观察的局部响应；
2. 光学身份或完整生命周期可靠地支持目标物理车辆在场；
3. 操作性时间映射与该观察相容；
4. 响应位置、尺度或方向与车辆物理量级相容；
5. 相邻帧、短窗或中窗没有产生未解释的非物理矛盾；
6. 主要邻车解释经过多车排他审查；
7. 主要背景解释经过背景生命周期审查；
8. 没有仍未解决的严重身份或 GT-link 冲突。

这八项是解释责任，不是八个分数、票数或通道通过数。联合支持必须保留每项原始证据、反证、适用范围和残余未知。

联合支持可以形成：

- ATTRIBUTION_PLAUSIBLE；
- ATTRIBUTION_SUPPORTED；
- MIXED_ATTRIBUTION；
- 对邻车或背景解释的 CONTRADICTED；
- 有边界的 possibly_complementary、lifecycle_compatible 或 different_vehicle_exclusivity。

联合支持仍不能自动形成：

- 完整响应边界已知；
- 固定物理散射部件已知；
- 跨车辆统一模板成立；
- GT 缺口内的 SAR 真值；
- 部署级最终框或自动标注。

### 3.4 仍不足以确定

已有证据可以支持局部归属，但不足以确定更强结论时，必须保存残余未知。

典型情况：

- 车辆与背景响应混合，局部归属可支持但精确边界未知；
- 同帧邻车解释受到约束，但仍不能唯一排除；
- 光学身份可靠，但目标时间段缺少直接 SAR GT；
- 局部响应与车辆尺度相容，但物理部件身份未知；
- 车辆真实存在，但某帧响应微弱、分裂或不可见；
- GT 自身 duplicate、diagnostic-only、identity conflict 或几何跳变。

正确保留 UNKNOWN、MIXED_ATTRIBUTION 或 BOUNDED_UNRESOLVED 不等于研究失败。

## 4. “禁止推导表”的正确读法

O1 禁止推导表中的每一行都应读作：

> 左侧单一状态不能被无条件等同或自动升级为右侧状态。

它不表示左侧状态在联合证据中没有约束作用。

例如：

- optical_vehicle_present 不能单独推出 SAR 响应归属，但可与直接 SAR 观察、时间相容、物理尺度、邻车排他和背景反证联合支持局部归属；
- sar_geometry_known 不能单独推出框内所有响应属于车辆，但可限制响应解释的合理位置和尺度；
- 跨帧相近不能单独推出同一物理部件，但可在同车身份和生命周期成立时支持相容或互补关系；
- tracker ID 连续不能单独确认完整物理身份，但可作为 identity_source 中的一项局部证据。

## 5. 证据联合记录合同

每个联合解释至少记录：

| 字段 | 要求 |
| --- | --- |
| claim | 被支持或被反驳的具体解释 |
| direct_observations | 直接可见事实，不混入推断 |
| constraining_evidence | 身份、时间、尺度、方向、排他和背景约束 |
| supporting_relations | 有边界的关系类型及作用范围 |
| competing_explanations | 当前车辆、邻车、背景、混合、无法判断 |
| counterevidence | 对当前解释及竞争解释的反证 |
| contradictions | 未闭合的身份、几何、GT 或生命周期矛盾 |
| residual_unknown | 当前仍不能确定的内容 |
| falsification_condition | 什么新证据会推翻或降级当前解释 |
| evidence_paths | 原始图、清单和规范图路径 |

不得只写 current vehicle is most likely，也不得只记录支持而省略主要替代解释。

## 6. 联合支持与直接观察的层级

sar_response_attribution_supported 属于 RELATION_INFERENCE，不是 DIRECT_OBSERVATION。

即使联合证据充分，记录仍必须区分：

- 直接看到了什么响应；
- 哪些证据限制了解释；
- 为什么目标车辆解释被支持；
- 为什么邻车或背景解释被反驳；
- 哪些替代解释仍成立；
- 哪些更强结论仍未知。

联合支持的证据越多，不意味着证据层自动升级为直接观察。

## 7. 矛盾闭合优先于正证累积

证据联合不是不断累加“正向特征”。一个严重未解决矛盾可以阻止 ATTRIBUTION_SUPPORTED：

- 身份线程与同帧多车顺序冲突；
- 操作性时间映射不适用；
- 位置或尺度出现非物理跳变；
- 固定背景在车辆进入前和退出后都持续；
- GT link duplicate 或 identity conflict；
- 错误车辆、错误时间或错误位置也能得到同等合理解释。

发生这些情况时，应降级为 ATTRIBUTION_PLAUSIBLE、MIXED_ATTRIBUTION、UNRESOLVED 或 CONTRADICTED，而不是通过增加证据数量抵消矛盾。

## 8. 明确禁止数值化替代

O1-R1 不引入：

- 加权总分；
- 证据票数；
- 通道通过数量；
- 大于某阈值即升级；
- 满足若干项即通过；
- 候选排名、top-k；
- winner 或 selector；
- temporal score；
- 用 GT 调整阈值或规则。

证据联合必须由解释、竞争假设、反证、矛盾、适用边界和残余未知闭合，而不是数值融合。

## 9. 研究期 GT 与部署期输入

研究期 GT 可以在正向结果冻结后用于逆向机制解释、错误归因和反事实核验。部署期与正向操作性盲审不得读取目标 SAR GT 中心、长宽、角度或由其生成的裁剪。

GT 揭示后的逆向证据不能回写、补充或修正已经冻结的正向理由和状态。只有这样，联合支持才能与事后合理化区分。

## 10. 修订结论

O1 的禁止推导继续阻止单一证据的无条件升级；O1-R1 同时明确允许相对独立的多模态、多时间尺度证据在完整记录反证和残余未知的条件下联合支持局部车辆响应归属。

本修订只冻结证据联合语义，不产生 GM_RM011 结果，不授权算法实现，也不改变 O1 关于完整边界、固定物理部件、跨车模板、GT 缺口和自动标注的未成立结论。
