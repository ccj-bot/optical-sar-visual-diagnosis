# OTY2 以点破面：光学约束、SAR 车辆物理响应与时序关联框架

Updated: 2026-07-11

## 1. 文档目的

本文件记录 WGV3.6A-A1.6、A1.7、A1.7R 之后形成的路线纠偏，防止后续 session 只继承“紧凑组合体、多假设、分支预算”等实现词汇，却忘记研究主目标：

> 利用光学时序给出的身份连续性假设、时间范围、运动趋势和可见状态，在 SAR 中寻找具有车辆物理尺度、散射部件结构和时序连续性的车辆响应状态。

本文件是 OTY2 事后机制诊断文档，不授权最终标注、修订 GT、选择器、排序器、训练或场景阈值调优。

## 2. 当前路线已经解决什么，尚未解决什么

### 2.1 已经解决或基本建立

1. 生成与评价分离，运行阶段不读取未来人工 SAR 目标框。
2. 多个 SAR 响应假设不能合成一个大包络伪装成定位成功。
3. 一个物理车辆可能对应多个离散 SAR 散射分量。
4. 歧义应保留为多个独立小假设，不能强制唯一化。
5. 光学方位/径向关系只能作为诊断约束，不能在未经验证时作为硬过滤。

### 2.2 尚未解决

A1.7R 当前主要回答：

> 哪些散射分量可以在局部几何上组成紧凑组合体，以及这些组合体如何作为多个独立假设传播？

但它尚未回答：

> 为什么一个紧凑组合体是车辆响应，而不是紧凑背景杂波、固定热点、道路或扇形弧线的一部分？

因此当前缺失层为：

```text
SAR 散射分量
    -> 车辆响应部件
    -> 车辆尺度物理结构
    -> 车辆支持的 SAR 观测实体
    -> 跨帧多假设关联
```

而不是直接：

```text
SAR 散射分量
    -> 紧凑组合体
    -> 跨帧多假设关联
```

## 3. “以点破面”的含义

“点”不是单个高亮像素，也不是某个单场景补丁。

本路线中的“点”是少量已经能够由人眼或多模态较清楚解释的局部正反窗口。

### 3.1 局部正向窗口

- 白色 SUV：SAR 27–31。
- 白色 SUV：SAR 78–81。
- 银色 MPV：SAR 270–273。
- 银色 MPV：SAR 289–290。

这些窗口中存在相对清楚的底部紧凑响应核心，可用于提出车辆响应结构假设。

### 3.2 局部反向或不确定窗口

- 白色 SUV：SAR 32、40、46、60、77。
- 银色 MPV：SAR 212–269 中的代表帧，尤其 239、243、250、260、269。
- 银色 MPV：SAR 276、280、284、288。

这些窗口包含背景弧线、远离分量、弱核心、结构中断或无法确认的响应，可用于主动证伪。

### 3.3 正确的以点破面循环

```text
局部可解释正例/反例
    -> 提出物理结构假设
    -> 转成可观测字段与硬约束
    -> 在其他窗口主动寻找反例
    -> 区分稳定机制、条件机制和错误机制
    -> 再决定是否进入跨帧关联
```

禁止的做法是：

```text
选择几个局部窗口
    -> 调阈值让这些窗口通过
    -> 把局部规则称为全局机制
```

“以点破面”要求小样本承担的是机制发现和证伪功能，不是阈值拟合功能。

## 4. 光学侧迁移的不是 SAR 框，而是约束消息

对一个光学车辆假设 `k`，迁移到 SAR 的消息可写为：

\[
\mathcal O_t^k =
\left(
\mathcal G_{id}^k,
\mathcal T_t^k,
\dot u_t^k,
\dot s_t^k,
q_t^k,
m_t^k,
\mathcal C_t^k
\right)
\]

其中：

- `\mathcal G_id^k`：检测、轨迹片段、连接边和竞争边构成的同车连续性假设图，不是身份真值。
- `\mathcal T_t^k`：可能对应的 SAR 时间范围及同步误差带。
- `\dot u_t^k`：光学横向运动趋势。
- `\dot s_t^k`：光学框尺度或相对深度变化趋势。
- `q_t^k`：光学轨迹稳定程度和断点可信度。
- `m_t^k`：完整可见、部分可见、截断、遮挡样、边界接触、部分到完整转换等状态。
- `\mathcal C_t^k`：邻车、多框、重复框和多目标竞争状态。

这些信息形成的是状态转移约束：

\[
C_O(X_{t-1}, X_t \mid \mathcal O_t^k)
\in
\{allowed, weakly\ supported, blocked\}
\]

光学侧允许回答：

- 当前应在哪个时间范围寻找同一车辆响应；
- SAR 方位或距离趋势是否与光学运动方向冲突；
- 遮挡或局部可见时，SAR 响应弱化、分裂或短缺失是否可以被容忍；
- 光学发生邻车竞争时，SAR 是否必须保留多个身份假设。

光学侧不能直接回答：

- 某个 SAR 亮点一定是车；
- 光学框中心应投影成哪个 SAR 框中心；
- 某个 SAR 组合体必然对应当前光学身份。

## 5. SAR 车辆响应的层级表示

### 5.1 散射原子

每个局部散射原子不应只记录质心、面积和强度，而应尽可能表示为：

\[
a_t^i =
(r_i, \phi_i, E_i, l_i, w_i, \theta_i, \kappa_i, \pi_i)
\]

其中：

- `r_i, \phi_i`：真实 SAR 极坐标位置；
- `E_i`：局部能量及相对能量；
- `l_i, w_i`：物理或映射后的主轴、次轴尺度；
- `\theta_i`：局部主方向；
- `\kappa_i`：点状、短线状、弧线状、角部样或块状等几何类型；
- `\pi_i`：跨帧持续、漂移和稳定程度。

散射原子只是观测，不是车辆。

### 5.2 车辆响应部件

车辆响应部件不是车辆真实机械零部件，而是 SAR 图像中的物理响应角色：

- `body_core`：主体或主能量核心；
- `side_ridge`：近侧/主侧脊线或短条带；
- `endpoint_hotspot`：前后端点或边界端热点；
- `corner_support`：角部高散射支持；
- `weak_far_side`：较弱的远侧响应；
- `background_arc`：背景弧线或扇形结构；
- `fixed_hotspot`：固定背景热点；
- `unresolved_atom`：证据不足的原子。

一个原子是否承担某种部件角色，必须由它与其他原子的尺度、方向、位置和时序关系共同决定。

### 5.3 车辆尺度壳体或支持结构

车辆支持结构记为：

\[
\Gamma_t = Compose(\mathcal P_t)
\]

其中 `\mathcal P_t` 为部件集合。`\Gamma_t` 至少应表达：

- 物理长轴和短轴；
- 主方向；
- 主体核心与端点、侧边或弱远侧响应之间的关系；
- 内部最大空白和最大部件间距；
- 与外部背景弧线或固定热点的分离；
- 是否形成车辆尺度，而不是小部件被错误提升成“小车”。

### 5.4 车辆响应状态

SAR 车辆状态写为：

\[
X_t = (\xi_t, \mathcal A_t, \mathcal P_t, \Gamma_t, m_t)
\]

其中：

- `\xi_t=(r_t,\phi_t,\dot r_t,\dot\phi_t)`：运动状态；
- `\mathcal A_t`：散射原子集合；
- `\mathcal P_t`：车辆响应部件集合；
- `\Gamma_t`：车辆尺度支持结构；
- `m_t`：当前响应形态状态。

## 6. 形状不是单一模板，而是条件语法

车辆在不同距离、姿态、遮挡、截断和信噪比下，不一定出现完整闭合边界。

允许的响应语法示例：

```text
full_shell
    -> body_core + side_ridge + endpoint_hotspot + weak_far_side

core_endpoint
    -> body_core + endpoint_hotspot

side_endpoint
    -> side_ridge + endpoint_hotspot

partial_vehicle_response
    -> partial_core + one_local_support

weak_temporal_response
    -> weak_core supported by short-window non-jump accumulation
```

因此车辆结构判定不是“必须拥有固定形状”，而是：

\[
G_{grammar}(\Gamma_t \mid m_t^{optical}, m_{t-1}^{SAR}) = 1
\]

即当前结构必须符合至少一种与光学可见状态、上一帧 SAR 状态相容的车辆响应语法。

例如：

- 光学处于局部可见或遮挡样状态时，可以允许 SAR 只保留局部核心；
- 光学完整可见且运动稳定时，长期只有一个极小孤立峰值，不能自动解释为完整车辆响应；
- 光学存在多目标竞争时，SAR 中多个车辆样结构必须保留竞争，不能因方向相似而合并。

## 7. 物理尺度约束

尺度约束应在 SAR 极坐标或地面坐标中计算，而不是只使用像素包络。

若：

\[
x_i=r_i\sin\phi_i,\qquad y_i=r_i\cos\phi_i
\]

对组合体点集求主方向 `e_parallel` 和垂直方向 `e_perp`，则物理长短轴为：

\[
L_t = \max_i e_{parallel}^{T}p_i - \min_i e_{parallel}^{T}p_i
\]

\[
W_t = \max_i e_{perp}^{T}p_i - \min_i e_{perp}^{T}p_i
\]

需要判断：

\[
(L_t, W_t, L_t/W_t)
\in \mathcal S_{vehicle-response}
\]

`\mathcal S_vehicle-response` 不是直接照搬真实车辆长宽，因为 SAR 响应受距离/方位分辨率、点扩散、近场几何、阈值截断和弱散射缺失影响。

当前可从已确认源锚点和局部视觉确认帧中，建立物理响应尺度审计分布，但不得为了让某个窗口通过而调阈值。

如果 `build_geometry()` 或现有配置不能证明坐标单位为米，必须明确写成“几何坐标尺度”，不得虚构公制物理尺度。需要单独审计单位来源、成像网格定义和坐标变换。

## 8. 正向车辆支持与负向背景排除必须闭环

车辆支持不能只证明“目标框内部有亮响应”，还必须证明“其他亮响应为什么不是车”。

### 8.1 正向证据

- 车辆响应物理尺度；
- 主体核心；
- 侧边/端点/角部等部件关系；
- 长短轴和主方向结构；
- 近侧强、远侧弱等相对能量关系；
- 间断但自洽的边界或壳体；
- 部件和主体的短时非跳变、渐进漂移。

### 8.2 负向证据

- 单个孤立峰值；
- 物理尺度过小的“小车”；
- 跨度过大的背景弧线；
- 沿扇形、道路、护栏或建筑边缘延伸的线状结构；
- 多帧固定不动的热点；
- 与光学车辆运动不一致的静态结构；
- 只有纹理或能量，没有车辆尺度部件闭合；
- 通过传递连接把远离原子错误并入主体。

正确 Gate 应同时包含：

\[
G_{vehicle} =
G_{scale}
\land G_{compact}
\land G_{grammar}
\land G_{temporal}
\land \neg G_{background}
\]

不能用高强度、方向一致或覆盖率去补偿明显错误的物理尺度。

## 9. SAR 与光学的结合顺序

正确顺序：

```text
SAR 统一局部观测
    -> 散射原子
    -> 车辆响应部件
    -> 车辆物理尺度/结构 Gate
    -> SAR 时序连续性
    -> 光学状态与运动兼容性
    -> 多假设关联
```

光学不应把明显背景样结构提升成车辆。只有先通过 SAR 物理可行性的结构，才进入光学兼容检查：

\[
\mathcal V_t =
\{X_t : G_{scale}=1, G_{compact}=1, G_{grammar}=1, G_{background}=0\}
\]

\[
\mathcal H_t =
\{X_t\in\mathcal V_t : C_O(X_{t-1},X_t)\neq blocked\}
\]

若 `|\mathcal H_t|=1`，才有唯一支持状态；若大于 1，保留多个独立假设；若为空，输出物理结构失败、光学兼容失败或证据不足，不得强制选择。

## 10. 与 A1.7R/A1.7R2 的关系

A1.7R 的正确贡献必须保留：

- 多假设不并框；
- 单分支搜索尺度有界；
- 传递式超尺度组合被阻止；
- 预算超限和歧义显式化；
- 极坐标光学关系只做诊断。

但后续统一观测、近重复假设归并和分支谱系工作，必须把输入从：

```text
all compact assemblies
```

改成：

```text
vehicle-supported observation entities
```

否则分支状态机只是在高效跟踪“紧凑亮响应”，仍不能证明它跟踪的是车辆。

建议先完成车辆响应语法与物理尺度审计，再把通过或部分通过的观测实体交给 A1.7R2 式统一观测和分支谱系机制。

## 11. 可借鉴方法及其边界

### 11.1 属性散射中心模型

可借鉴：

- 散射原子的参数化属性；
- 点状、线状和典型几何响应类型；
- 由局部散射中心组成目标结构图。

不可直接照搬：

- MSTAR 车型模板；
- 分类器结果；
- 将散射中心拟合得分当成选择器。

### 11.2 扩展目标跟踪

可借鉴：

- 一个目标在一帧中产生多个测量；
- 运动状态与目标范围/结构状态联合表示；
- 多个子对象共享一个整体运动状态。

对应本项目：主体核心、侧边、端点可独立出现或消失，但应共享车辆整体 `r, phi, dr, dphi` 状态。

不可直接照搬：

- 用一个椭圆随机矩阵代表所有车辆响应；
- 只估计外包范围而忽略散射部件角色。

### 11.3 随机超曲面/星凸形状模型

可借鉴完整壳体或较连续边界帧中的形状估计。

不适合直接用于离散、断裂、多热点和弱响应帧，因此只能作为某一种响应状态模型。

### 11.4 航迹前检测

可借鉴：

- 不要求每帧先形成硬检测；
- 沿受限运动路径积累弱能量；
- 通过短时序支持恢复单帧阈值下丢失的弱核心。

可用于检验白色 SUV 32–77、银色 MPV 212–269 等弱中间段是否存在连续但单帧不显著的车辆响应。

不可直接用未来目标框定义积累路径。

### 11.5 多假设跟踪和随机有限集思想

可借鉴：

- 分支父子谱系；
- 歧义 episode；
- 分支分裂、合并、消失；
- 不在单帧强制唯一化。

当前阶段不必实现完整概率滤波，先保证观测实体、谱系和恢复定义正确。

### 11.6 参考方法条目

- Baum, M.; Hanebeck, U. D. *Extended Object Tracking with Random Hypersurface Models*, 2013.
- Granstrom, K. *An Extended Target Tracking Model with Multiple Random Matrices and Unified Kinematics*, 2014.
- Peng, B. et al. *Scattering Model Guided Adversarial Examples for SAR Target Recognition: Attack and Defense*, 2022。该文使用有效属性散射中心模型描述典型几何结构；本项目只借鉴物理参数化思想。
- Lu, J. et al. *Track-before-detect Algorithm based on Cost-reference Particle Filter Bank for Weak Target Detection*, 2023。本项目只借鉴低信噪比下的时序能量积累思想。

## 12. 下一阶段的最小正确问题

下一阶段不应直接问：

> C1D/C1E 如何减少分支数量？

应先问：

> 在局部正反窗口中，能否用物理尺度、散射部件语法、背景排除和短时漂移，把“车辆支持响应”与“紧凑背景响应”区分开？

只有该问题得到局部且可证伪的支持后，才进入：

> 如何把车辆支持的观测实体进行统一提取、等价归并和多假设时序关联？

## 13. 下一阶段建议顺序

### Stage A：车辆响应语法审计

- 逐帧显示散射原子、部件角色、物理尺度和背景结构；
- 由 Codex 实际打开图像进行对象级中文判断；
- 不使用帧号模板自动生成判断；
- 不做最终框。

### Stage B：物理可行 Gate 审计

- 检查正向窗口是否保留车辆核心；
- 检查反向窗口是否排除背景弧线和远离分量；
- 主动记录正例被拒和负例被接受的反例；
- 不通过局部调阈值掩盖反例。

### Stage C：部件级短时连续性

- 跟踪主体核心、端点、侧边等角色；
- 允许部件出现/消失；
- 检查它们是否共享一个整体运动状态；
- 对弱响应测试短窗口能量积累。

### Stage D：统一观测与多假设谱系

- 每帧只提取一次统一观测；
- 归并近重复观测；
- 只让车辆支持或车辆可能的观测实体进入分支；
- 建立持久分支谱系和真实歧义恢复定义。

## 14. Stop Conditions

以下任意情况出现时，不得宣称车辆响应机制成立：

- 正向车辆窗口和背景窗口无法在物理尺度或结构上区分；
- 车辆判定仍只依赖质心、面积、强度或包络；
- 车辆部件角色由帧号或目标框覆盖率自动生成；
- 明显背景弧线仅因光学运动方向一致而被接受；
- 小孤立峰值被称为完整车辆；
- 使用未来人工框决定运行阶段的原子、部件或积累路径；
- 只解释为什么目标是车，不解释为什么邻近强响应不是车；
- 局部窗口阈值被调到刚好通过，而没有跨窗口证伪。

## 15. 当前阶段结论

当前主线不是放弃 A1.7R 的因果多假设框架，而是在其前面补上物理语义层：

```text
光学不确定时序消息
        +
SAR 散射原子 -> 车辆部件 -> 车辆尺度结构
        +
SAR 部件级短时漂移
        -> 车辆支持观测实体
        -> 有界多假设关联
```

这条路线同时继承了：

- 早期“物理结构优先、非加权融合”；
- 光学工作时间线图和不确定连续性场；
- A1.6 的无泄漏因果边界；
