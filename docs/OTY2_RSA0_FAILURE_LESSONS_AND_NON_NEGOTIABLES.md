# OTY2-RSA0 失败经验与不可协商规则

日期：`2026-07-17`

本文件把 S0、S1-L、S1-LR、S1-LR2、S1X 和 S1D0 已经暴露的错误固化为后续实现门槛。它不是新的实验结果，也不为任何算法授权。

## 1. 现实观察优先于单项指标

连续 SAR 中可直接看到近水平主响应、局部热点和状态变化时，一个低 recall、低 F1 或背景对照失败只能否定当前表示/规则，不能先否定响应存在。

不可协商规则：指标必须解释“方法为什么没有承载已审阅信号”，不得把方法失败改写成现实不存在。

## 2. 先定义真实研究对象，再设计方法

S1X/S1D0 先由 robust-z、连通片和持久频率定义“响应”，随后再评价这些响应；这使算法内部对象替代了人眼实际识别对象。

不可协商规则：RSA0 先用连续审阅建立骨架、确定/可能响应、背景和 unresolved，再对冻结对象诊断表示。表示不得反向决定参考语义。

## 3. 光学可观测生命周期不等于 SAR 响应存在周期

光学 entry/exit 由相机视野和扫描决定。当前大量车辆静止，车辆可能在光学进入前已经位于雷达成像区，光学退出后也可能继续产生 SAR 响应。

不可协商规则：光学生命周期只控制身份何时可知、何时可输出、何时关闭；不得用它判断 SAR 像素正负。

## 4. pre-entry 与 closed/post-exit 不能自动成为背景

S1D0 v1.1 使用 `ABSENT/CLOSED` 时段壳内 positive frequency 构造 inside-shell background。该实现对“车辆离开雷达成像区”没有独立证据，可能把真实车辆响应写成背景。

不可协商规则：RSA0 禁止从 pre-entry、closed 或 post-exit 自动生成同位置背景阴性。背景必须来自同帧、同径向或邻近径向、相似显示范围、与车辆 GT 扩张邻域不重叠的直接审阅结构。

## 5. SAR GT 可用于研究发现，但不能进入部署推理

GT 在当前任务中能确认物理车辆身份、合理邻域、其他车辆排除、研究坐标和事后评价。禁止的是目标 GT 参与部署推理或根据评价结果反向调规则，不是禁止研究期查看 GT。

不可协商规则：每个 GT 使用点必须标记角色；`RESEARCH_ORACLE_COORDINATE_ONLY` 与 optical proxy/deployment 输入必须分开报告。

## 6. 完整车体 GT 不是可见响应 Mask

GT 框描述车辆空间占据，不描述显示域内哪些像素当前有响应。框内可能是暗区、背景、其他局部结构或混合区。

不可协商规则：整个 GT 框不得默认标为 `DEFINITE_TARGET_RESPONSE`，也不得作为可见响应的默认分母。

## 7. 大矩形不能把内部所有像素都当正响应

S1D0 visible-response reference 虽与完整 GT 分开，但仍以轴对齐矩形 region 存储类别，评价函数将矩形内部整体作为同类像素。它比完整 GT 更接近直接审阅，却仍会覆盖矩形内不属于细响应骨架的像素。

不可协商规则：RSA0 的主参考几何必须是 polyline、sparse scribble 或 polygon；bbox 只能作上下文、裁剪或索引，不能单独定义响应。

## 8. 高 precision、极低 recall 的亮点不等于恢复响应对象

S1D0 discovery precision 约 `0.918`，但可见响应 recall 仅 `0.0265`。这说明命中的少量亮点较干净，不说明主响应和间歇部件已经恢复。

不可协商规则：必须分别报告骨架覆盖、确定响应覆盖、弱态保留、背景激活和跨帧连续性；不能用 precision 单项替代对象恢复。

## 9. 最亮点、质心和 persistent pixel 不是车辆中心

直接审阅已经确认最亮局部段会在主带左右变化；背景热点也可能长期稳定；S1X/S1D0 的 joint centroid 只是输出 mask 的质心。

不可协商规则：RSA0 不输出车辆中心。响应骨架和局部部件可有几何中心，但不得升级为车辆物理中心或最终框中心。

## 10. 背景复现一个结构形式不等于复现完整车辆关系

扇形弧可复现横带加热点，竖线可有更高亮度或清晰度，固定背景也可表现持久性。单项相似不能自动否定目标；反之，单项不同也不能证明车辆所有权。

不可协商规则：背景反事实必须比较方向、相对位置、局部部件关系、跨状态表现和世界稳定性；不得用单个亮度、线性或持久性特征作总判决。

## 11. 响应恢复未通过前不构造动力学结论

S1D0 的 graph 可以在三个案例中产生 birth、split、merge、migration 等同名事件，但恢复入口未通过，GM_RM019 又没有正参考。这些名称只描述阈值组件图的变化。

不可协商规则：在可信响应对象恢复和跨窗口复现之前，所有事件词汇冻结为历史相关性记录，不进入物理解释或项目成功证据。

## 12. 映射失败、参考失败和响应恢复失败必须分层

GM_RM019 当前既可能受跨场景壳映射影响，也缺少可判定正响应参考。把零值 recall 解释成恢复失败会混淆两个层级。

不可协商规则：

- 壳未覆盖可见对象：mapping/shell placement debt；
- 无法建立正参考：reference debt；
- 壳覆盖且参考充分但表示未命中：representation/recovery failure；
- 背景混入：background separation failure。

不允许用一个总的 READY/NOT_READY 覆盖这些层。

## 13. 一轮任务只能关闭一个研究层级

S1D0 同时扩展完整生命周期、跨场景、压力案例、背景规则、响应图和事件解释，导致基础恢复失败与其他失败层交织。

不可协商规则：RSA0 只做少量短窗 atlas 与表示诊断；不扩展完整生命周期、跨三场景自动化、压力恢复或动力学。

## 14. 不用加权总分掩盖机制冲突

不同表示可能分别擅长骨架、弱响应、弧线排除或热点排除。压成单一分数会隐藏方向冲突、归一化依赖和 GT-only 能力。

不可协商规则：每个通道独立评价，形成非支配集合；禁止综合分、自动 winner 和“最佳通道”单结论。

## 15. 不回到候选库、selector、ranking 或 winner

历史路线已明确从逐帧候选工程转向时序对象。RSA0 的对象也不是每帧候选集合，而是一个短窗中的冻结响应语义。

不可协商规则：不得生成 candidate bank、排名、Gate、oracle winner 或最终框；表示通道不得被包装成候选打分器。

## 16. validator PASS 不代表科学有效

哈希、schema、行数、重放一致性和 Git clean 只能证明工程一致性。S1D0 的工程门可以全部通过，同时恢复入口仍失败。

不可协商规则：科学结论必须以直接视觉事实、反事实、分层指标和限制为主；validator 只验证产物契约。

## 17. 世界坐标不能默认等于原始像素零位移

S1-LR 已经确认 GM_RM017 330–350 中背景和 GT 共同横移约 125–126 px。原始像素中“移动”不等于车辆运动，“不动”也不自动等于世界固定。

不可协商规则：世界稳定坐标必须由多背景共同运输和留出背景验证建立；运输拟合不得使用目标响应或 GT 轨迹。

## 18. Raw GT 逐帧位移不是物理运动真值

S1-LR2 发现 20 个相邻对中 19 次标注来源家族切换，Raw/Smoothed GT 相对共同运输都有明显残差。GT 可定位研究邻域，但相邻帧增量受标注抖动影响。

不可协商规则：GT 条件坐标可用于研究期对齐，不得把 Raw GT adjacent displacement 当光流真值或动力学证据。

## 19. 方向和尺度先验必须保持宽范围

当前 optical proxy、单车校准和 8-bit 显示不足以确定唯一车体方向、中心或尺度。S1-L 的参数审计也没有获得可识别物理区间。

不可协商规则：RSA0 可比较世界方向、fan radial/tangential、GT 研究期方向和 optical proxy 方向范围，但不得把任一方向写死为水平或从单一指标估计精确姿态。

## 20. 标注应保守允许空白和不确定

车辆与背景混合时，强制二分类会把审阅不确定性隐藏到正负标签中。

不可协商规则：

- 宁可缩小 definite response，也不扩大到不确定边界；
- probable 与 unresolved 必须独立存在；
- 无法判断时允许没有 definite positive；
- GM_RM019 若无可判定正参考，必须记录 debt，而不是虚构正样本。

## 21. atlas 必须先冻结再评价

如果根据某个通道的 AUC、recall 或视觉效果修改 scribble/polygon，评价将反向污染参考。

不可协商规则：窗口、关键帧、所有几何、背景控制、审阅页和配置必须先形成聚合 SHA256。任何后续标注修正都必须发布新 atlas 版本并完整重跑。

## 22. 只看统计不看图片无效

旧阶段多次出现统计似乎支持、直接图像却暴露背景弧线、固定强线、混合区域或错误归属的情况。

不可协商规则：每个关键帧必须有包含 optical identity、原始 SAR、GT 上下文、响应几何、背景、unresolved、局部放大和前后帧的审阅页；Codex 必须实际查看图像并记录具体帧号与路径。

## 23. 失败后的正确退出

若 canonical 窗口无法建立可信 atlas，或所有表示只响应孤立最亮点，不允许继续追加阈值、形态学规则或第二/第三次最小修复。

不可协商规则：明确判断 8-bit 显示域是否不足，是否需要原始幅度/功率、复数图、固定灰度 mapping、成像配置或更完整几何数据，然后停止本轮。
